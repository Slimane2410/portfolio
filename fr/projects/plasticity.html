01 · OBJECTIF

Connecter le banc de test au modèle numérique

Une poutre en flexion trois points et un portique encastré ont été chargés au-delà du domaine élastique. Les courbes expérimentales, l’analyse limite et les résultats non linéaires par éléments finis ont ensuite été comparés pour identifier les limites d’élasticité, les rotules plastiques et les charges d’effondrement.

PYTHON-DRIVEN ABAQUS

Simulation construite via du code

Un script Python a été adapté pour créer et paramétrer les modèles Abaqus avec la géométrie et les propriétés matérielles sélectionnées. Cela a rendu la configuration 1D/2D reproductible et a permis l’étude de plusieurs configurations de chargement.
