01 · OBJECTIVE

Connect the test bench to the numerical model

A three-point bending beam and a fixed frame were loaded beyond the elastic range. Experimental curves, limit analysis and nonlinear finite-element results were then compared to identify yielding, plastic hinges and collapse loads.

PYTHON-DRIVEN ABAQUS

Simulation built through code

A Python script was adapted to create and parameterize the Abaqus models with the selected geometry and material properties. This made the 1D/2D setup reproducible and supported the study of multiple loading configurations.
